# TriOmicNet

TriOmicNet is a multi-layer network diffusion framework for cancer driver gene identification by integrating three types of scores derived from gene expression, mutation, and regulatory/network information.

## Overview

The TriOmicNet workflow consists of five main steps:

1. Expression data preprocessing
2. Multilayer network construction
3. Calculation of control ability score and regulatory potential score
4. Calculation of multi-network diffusion score
5. Integration of the three scores by singular value decomposition (SVD)

These steps correspond to the methodological framework described in the manuscript.

## Repository Structure

- `code/`
  - `TriOmicNet.R`: main script for running the TriOmicNet workflow
  - `DE_Score.R`: differential expression score calculation
  - `construct_layer.R`: multilayer network construction
  - `random_walk.R`: random walk with restart
  - `remrna_exp.m`: optional MATLAB script for expression matrix preprocessing
- `data/`
  - `BRCA/`, `LUAD/`, `PRAD/`: cancer-specific input data
  - additional `.RData` and `.rda` files: shared biological network resources used by the method

The repository contains the input files required for the BRCA, LUAD, and PRAD analyses used in this study.

For expression preprocessing, the MATLAB script `remrna_exp.m` can be used if MATLAB is available. For convenience, a processed BRCA expression file is also provided, so the BRCA example can be run without repeating the MATLAB preprocessing step.

## How to Run

Before running the code, please set the working directory to the root directory of this repository.

Run the main workflow with:

```bash
Rscript code/TriOmicNet.R
```

The current script contains the core analysis pipeline described in the manuscript and reads the required helper scripts and input data from the repository.

The repository includes data resources for the BRCA, LUAD, and PRAD cohorts analyzed in the manuscript. The same workflow is used for the corresponding cancer-specific input files provided under `data/`.

## Main Analysis Procedure

### Step 1. Expression data preprocessing

The expression matrix is processed and filtered before downstream analysis. If MATLAB is not available, the processed BRCA file provided in the repository can be used directly for the BRCA analysis.

### Step 2. Multilayer network construction

The multilayer network is constructed using mutation data, biological interaction resources, and differential expression information. This step is executed automatically by the main script through
code/construct_layer.R and does not require a separate command.

### Step 3. Score calculation

TriOmicNet computes:

- a control ability score
- a regulatory potential score

These scores quantify different aspects of gene importance in the cancer-related multilayer network.

### Step 4. Multi-network diffusion score

Network diffusion is performed on multiple biological interaction networks, and the resulting signals are integrated into a multi-network diffusion score.

### Step 5. Final score integration

The three component scores are standardized and integrated by singular value decomposition (SVD) to generate the final prioritization score for candidate driver genes.

## Output

The main output of the workflow is a final gene ranking table generated by the main script. This output contains the integrated prioritization score for candidate cancer driver genes.

Main result file:

- `final_score.csv`: final integrated prioritization scores for candidate driver genes

This output corresponds to the final ranking analysis described in the manuscript.

## Reproducing the Main Results

The revised manuscript includes the main analyses for BRCA, LUAD, and PRAD, as well as the additional experiments described in the revised version. To improve reproducibility, the repository documentation has been updated to better reflect the workflow used in the manuscript revision.

The main executable command is:

```bash
Rscript code/TriOmicNet.R
```

This command runs the core TriOmicNet pipeline using the corresponding input files provided in the repository. The resulting output table can be used to reproduce the final driver-gene prioritization analysis reported in the manuscript.
